# The transport bar {#transport-bar}

The bar along the top of the window controls playback and settings for the whole song. From left to right:

| Control                   | What it does                                                                                                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **rebeat** + project name | Click the name to open the [project browser](command:project.home). A small dot next to it means there are changes that haven't been saved yet (they save automatically within a second).                     |
| **Play / Stop**           | Starts and stops playback ({{key:transport.toggle}}). Playback starts at the page you're editing.                                                                                                             |
| **Rec**                   | Record ({{key:transport.record}}). While playing, pads you hit are written into the pattern. With an armed audio track, it records a loop. See [Recording](#recording) and [The loop station](#loop-station). |
| **Loop**                  | How long a loop recording is: the page length, or 1, 2, 4 or 8 bars.                                                                                                                                          |
| **1.1.1**                 | Where the playhead is: bar . beat . step.                                                                                                                                                                     |
| **BPM**                   | Tempo. Drag up/down or scroll to change it; double-click to reset to 120. Hold Shift while dragging for fine steps.                                                                                           |
| **Tap**                   | Tap a few times in time with the music to set the tempo ({{key:transport.tap}}).                                                                                                                              |
| **4/4**                   | Time signature: 4/4, 3/4, 5/4, 6/8 or 7/8.                                                                                                                                                                    |
| **Click**                 | Metronome on/off ({{key:transport.metronome}}). The click isn't recorded or exported.                                                                                                                         |
| **1234**                  | Count-in: one bar of clicks (or two, see [Settings](#settings)) before playback or recording starts from a stop.                                                                                              |
| **Swing**                 | Swing for the whole song: 50% is straight, higher values delay every second step. Pages and tracks can have their own swing.                                                                                  |
| **Q**                     | Quantize for live recording: hits snap to 1/4, 1/8, 1/16 or 1/32 notes, or keep their exact timing (Off).                                                                                                     |
| **Page / Song**           | **Page** repeats the page you're on; **Song** plays the pages in order, with their repeats ({{key:transport.mode}}).                                                                                          |
| **CPU**                   | How busy the app is drawing and scheduling.                                                                                                                                                                   |
| Level meter               | The level of the master output (left and right).                                                                                                                                                              |
| Audio status              | Green when sound is running.                                                                                                                                                                                  |
| ⌘                         | The [command palette](command:app.palette).                                                                                                                                                                   |
| Layout button             | Switch between layout presets and show any panel. See [Panels and layouts](#panels).                                                                                                                          |
| Full screen               | The whole app full screen ({{key:view.fullscreen}}). Esc leaves full screen.                                                                                                                                  |
| **?**                     | This guide.                                                                                                                                                                                                   |
| Speech bubble             | **Explain mode** ({{key:app.explain}}): hover over any button for a card that explains it, with its shortcut. See [Explain mode](#getting-started-explain-mode).                                              |
| Gear                      | [Settings](command:app.settings) ({{key:app.settings}}).                                                                                                                                                      |

On narrow windows some controls hide; they're always available in the command palette.
